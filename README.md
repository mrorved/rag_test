# CVGaudio RAG Assistant (ЮНИТРЕКС)

Умный AI-консультант и система подбора профессионального звукового оборудования для сайта [cvg-rus.ru](https://cvg-rus.ru).

## 🚀 Возможности
- **Инженерный подбор оборудования:** понимает сложные запросы (например, *"двухзонный трансляционный усилитель 100V с Bluetooth для ресторана на 80 м²"*).
- **RAG по каталогу:** опирается на актуальную базу данных товаров, серий (M, TR, Rebox, CRX, ODF) и типовых решений.
- **Поддержка GigaChat (Сбер):** работа без блокировок, капч и VPN на территории РФ с моделью `GigaChat-2`.
- **Защита от промпт-инъекций и атак:** встроенный Guardrail-фильтр, блокирующий попытки взлома (смену роли, рецепты, код, слив чужих данных).
- **Встроенная авторизация:** защита стенда логином и паролем для безопасного тестирования в Portainer.
- **Встроенный сбор заявок (Лидогенерация):** кнопка «Заявка инженеру» сохраняет контакты с историей диалога + просмотр лидов прямо в веб-интерфейсе.
- **Готовность к Portainer / Docker:** запуск в 1 клик на любом сервере через `docker-compose`.

## 🛠 Быстрый запуск

### Вариант 1. В Docker и Portainer (Рекомендуемый для сервера)

1. Склонируйте или скопируйте папку проекта на сервер с Portainer.
2. Настройте файл `.env`:
```env
LLM_PROVIDER=gigachat
GIGACHAT_CREDENTIALS=ваш_authorization_key
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2

AUTH_ENABLED=true
AUTH_USERNAME=admin
AUTH_PASSWORD=ваш_пароль
```
3. В веб-интерфейсе **Portainer**:
   - Перейдите в **Stacks** -> **Add stack**.
   - Назовите стек `cvg-assistant` и вставьте содержимое `docker-compose.yml` (или соберите из папки).
   - Нажмите **Deploy the stack**.
4. Готово! Сервис доступен по адресу `http://ip-сервера:8000`.

---

### Вариант 2. Локально через Python

```powershell
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск сервера с автоперезагрузкой
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
Откройте в браузере: [http://localhost:8000](http://localhost:8000)

## 📦 Обновление базы знаний

Для повторного парсинга свежих товаров с сайта `cvg-rus.ru`:

```bash
python parser/scrape_catalog.py
```
Скрипт обновит данные в `data/knowledge_base.json`.
